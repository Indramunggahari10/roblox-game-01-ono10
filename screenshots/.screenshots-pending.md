# Screenshots — pending Studio playtest

This folder intentionally holds no images yet. There is no Roblox Studio on
the Linux machine that built this game, so no real gameplay screenshots
could be taken here, and no screenshot was fabricated or copied from the
starter.

Before submitting, the owner must:

1. Open `game.rbxl` in Roblox Studio on Windows or macOS.
2. Press Play and play through the game (start screen, collecting crystals,
   the portal, the win screen).
3. Capture 3–4 screenshots while the game is running:
   - `1-start.png` — the start screen (title + PLAY button)
   - `2-play.png` — mid-game (HUD, crystals, lava, platforms)
   - `3-end.png` — the win screen (or the lose screen)
   - optionally `4-level2.png` — a later level
4. Keep each file at most 256 KiB, long side at most 1280 px, short side at
   least 480 px. Re-encode as JPEG or scale down if a Studio capture is
   larger.
5. Delete this note file before submitting (the gate counts non-image files
   only if they start with `.`; this file is removed so screenshots/ holds
   only the images).

The first file by name is the cover shown largest to the judge, so make
`1-start.png` the best-looking screen.
